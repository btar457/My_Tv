# My TV — قائمة قنوات IPTV

قائمة قنوات IPTV (رياضة، ترفيه، أفلام، مسلسلات، موسيقى) بصيغة M3U، تُنظَّف وتُفحص تلقائياً كل يوم.

## طريقة الاستخدام

أضف هذا الرابط في أي مشغّل IPTV (VLC، TiviMate، IPTV Smarters، Kodi…):

```
https://raw.githubusercontent.com/btar457/My_Tv/main/playlist.m3u
```

القنوات مقسّمة إلى مجموعات:
- **رياضة**: رياضة عربية، كرة القدم، قتال وملاكمة، سباقات سيارات وخيول، غولف وتنس، رياضات أمريكية، بوكر وألعاب، رياضات متنوعة.
- **ترفيه عربي**: ترفيه عام، أفلام، مسلسلات، كوميديا، موسيقى، ثقافة ووثائقي.

### قسم الكبار (+18)

مشروع iptv-org توقف عن نشر قنوات الكبار منذ يناير 2024، فلا يوجد مصدر عام لها هنا. تطبيق الأندرويد فيه قسم +18 محمي برقم سري، تضيف إليه روابط M3U خاصة بك من «المصادر».

## الملفات

| الملف | الوصف |
|---|---|
| `channels.json` | المصدر الأساسي: الاسم، الرابط، المجموعة، الشعار، وحالة الفحص |
| `playlist.m3u` | القائمة الرئيسية، تُولَّد تلقائياً — **لا تعدّلها يدوياً** |
| `sources.json` | مصادر خارجية تُستورد منها قنوات جديدة، وتحويل تصنيفاتها إلى مجموعات عربية |
| `scripts/update_playlist.py` | سكربت التنظيف والفحص والتوليد (Python بدون مكتبات خارجية) |
| `.github/workflows/update.yml` | تشغيل السكربت يومياً على GitHub Actions |

## كيف يعمل التحديث التلقائي

كل يوم يقوم GitHub Actions بما يلي:

1. استيراد القنوات الجديدة من المصادر في `sources.json` (قنوات iptv-org العربية الترفيهية).
2. حذف القنوات المكررة (نفس الرابط).
3. تصنيف كل قناة في مجموعة حسب اسمها.
4. فحص كل رابط: يجب أن يرد الخادم بقائمة HLS صالحة (`#EXTM3U`) أو بث فيديو.
5. جلب الشعار ومعرّف EPG ‏(`tvg-id`) من قاعدة بيانات [iptv-org](https://github.com/iptv-org/iptv) عند توفرها.
6. إعادة توليد `playlist.m3u` و`playlist_adult.m3u`.

قواعد الإخفاء والحذف:

- القناة التي تفشل **3 مرات متتالية** تُخفى من `playlist.m3u`، وتبقى في `channels.json` لتعود تلقائياً إذا اشتغلت.
- القنوات الموسومة `[Geo-blocked]` أو `[Not 24/7]` تُمنح **14 مرة** قبل الإخفاء، لأن خوادم GitHub موجودة خارج المنطقة وقد لا تصل إليها.
- القناة التي تفشل **30 مرة متتالية** تُحذف من `channels.json` (وتبقى في سجل git). إذا كانت مستوردة يُحفظ رابطها في `removed_urls` حتى لا يعيد المستورد إضافتها.

لإضافة مصدر أو تصنيف جديد (مثلاً أخبار أو أطفال) أضفه في `sources.json`؛ أسماء التصنيفات هي تصنيفات iptv-org مثل `News` و`Kids` و`Religious`.

## إضافة قناة

أضف عنصراً إلى `channels_list` في `channels.json`:

```json
{ "name": "اسم القناة (1080p)", "url": "https://example.com/live/index.m3u8" }
```

عند الدفع إلى `main` يعمل السكربت تلقائياً، فيصنّف القناة ويعيد توليد `playlist.m3u`.

للتشغيل محلياً:

```bash
python3 scripts/update_playlist.py                  # تنظيف وتوليد فقط
python3 scripts/update_playlist.py --check --logos  # مع فحص الروابط والشعارات
python3 scripts/update_playlist.py --import --check --logos  # التشغيل اليومي الكامل
```

## ملاحظة

الروابط مجمّعة من مصادر عامة، والمستودع لا يستضيف أي محتوى. بعض القنوات قد تكون محجوبة جغرافياً أو غير متاحة دائماً.
